## 固定方法

- A/B/C 使用相同的固定初值：paper distance `0.20`，paper shape `0.004`；不估计、搜索或选择初值。
- C 使用一个全局 log-distance 均值和每个非夹持物理粒子的零均值局部变量：
  `log(k_i)=log(0.20)+c+delta_i`。
- 局部变量使用物理网格邻接图正则、RGB 轨迹观测度加权和对角 Gauss-Newton/LM 更新。
- shape 以 `0.15` 弱耦合相同 log 场；volume、阻尼和夹持耦合固定。
- 五帧因果 H1/H3/H5 窗口；每十帧尝试一次更新；两条确定性 Warp 方向有限差分；方向余弦门限 `0.90`；图 CG 为八轮。
- 深度仅来自 FoundationStereo RGB 估计；不把仿真 GT 深度、GT 刚度、未来帧或最终评估点用于优化。
